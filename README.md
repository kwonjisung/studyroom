# 스터디룸

영어 뉴스·일본어 애니메이션 명대사로 매일 공부하는 개인 학습 앱입니다.

- **홈** — 오늘의 영어·일본어 학습지, 이번 주 진행 상황, 영어·일본어 통합 달력
- **영어** — 뉴스 기사 본문(핵심 단어 밑줄·문법 표시), 본문 MP3(느린 발음 → 보통 발음), 단어 3번 듣기, 문법, 전체 해석, PDF
- **일본어** — 명대사와 후리가나·한글 발음, 장면, 단어, 기초, 문법, 비슷한 표현, PDF, 앞으로 7일 일정
- **테스트** — 일요일 주간 테스트(영어·일본어) PDF

## 구성

```
index.html            앱 (파일 하나, 빌드 필요 없음)
en/entries.json       영어 학습지 데이터
en/tests.json         영어 주간 테스트 목록 (첫 테스트 이후 생김)
en/pdf/  en/audio/    영어 학습지 PDF · 본문 MP3
ja/entries.json       일본어 학습지 데이터
ja/schedule.json      일본어 한 달 일정
ja/tests.json         일본어 주간 테스트 목록
ja/pdf/               일본어 학습지 PDF
```

앱은 `en/`, `ja/` 아래 JSON을 읽어 화면을 그립니다. 파일이 없으면 그 부분만 비워 둡니다.

## 실행

정적 파일이라 어디서든 열 수 있습니다.

- 로컬: `python3 -m http.server` 후 http://localhost:8000
- GitHub Pages: Settings → Pages → Branch `main` / `(root)`

> `index.html`을 파일로 바로 열면(file://) 브라우저가 JSON을 읽지 못하니 위처럼 서버로 여세요.
